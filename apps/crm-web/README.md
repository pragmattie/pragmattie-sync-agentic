# apps/crm-web

The PragMattie Sync CRM web app: Vue 3, Vite, Vuetify, Pinia, Vue Router. The product surface for
leads, accounts and contacts, pipeline and sales forecasting, talking to `apps/api`.

Looks like a real deployed product: no development pages, menus, metrics or "demo"/"simulated"
labels belong here.

Agent-built; see `CLAUDE.md` at the repository root for the rules that govern it.
